# M26 新着でない履歴カードの時間経過による非表示

- 目的: 「新着」ではない履歴カードが時間経過で画面に残り続けないようにする。時間は分単位を想定。
- 対象: 履歴窓上のカードの一時表示。「消える」は画面からの非表示で、保存履歴の削除・受信済み回答の消去ではない。過去の履歴は再度開いて読める。
- 対象外: 新着の自動解除、回答待ちの解除、履歴の削除、購読や送受信の変更。
- 依存: M03 の履歴表示。M14 の新着状態と整合する。M14 の完了を設計着手の一律条件とはしない。
- 作業ブランチ（予定）: `milestone/M26-history-card-timeout`。優先度は着手時に確認。
- 承認根拠: 2026-11-26 JST のユーザー指示、MGMT-25。

## 完了条件（暫定）

| ID | 条件 | 確認方法 |
| --- | --- | --- |
| AC-01 | 新着ではない履歴カードは、決めた分単位の表示時間を過ぎたら自動で非表示になる。新着のカードはタイマーで消えない。 | 短縮したテスト時計、混在・境界時刻の確認 |
| AC-02 | 非表示は保存履歴、未回答要求、通常の送受信、新着件数を変更しない。非表示になった内容は履歴を開き直して確認できる。 | 再表示・再起動・新着状態の回帰 |
| AC-03 | 既読に変わったカード、複数カード、操作中の長文で意図しない消え方や操作不能がない。 | Windows の実画面と状態遷移の確認 |
