# M09 メッセージ・マウスイベントに応じた羽衣ちゃんのアクション

## 定義

- ID: M09
- 優先度: 中（M04と早期並行着手、2026-11-25）
- 目的: 羽衣ちゃんがメッセージのやり取りやマウスイベントに応じてアクションするようにする。
- 対象範囲: 送信受付・受信・マウス操作の仕草と再生。ユーザーの追加指示に従い、返信待ちには顎に指を添えた思案の仕草と実際に動いたウィンドウへの視線追従を含める。 通常待機・返信待ちともに、本体の近くと会話・状態パネルの操作先へ顔を向ける。
- 対象外: 自律的なランダム移動（M10）、Dotの能動的な発言経路（M04）、通信障害復旧（M06）、新着解除規則（M14）。
- 依存ID・着手条件: M03のキャラクター表示・操作UI、M08の管理起動（いずれも完了）を基盤とする。M04の完了を一律の着手条件としない。
- 作業ブランチ: `milestone/M09-character-reactions`
- 分岐元main SHA: `78671596e4d90bffe3446af930182fa85ac4e966`
- 担当: 本会話のAI（状況別設計・実装・検証）、ユーザー（見た目の選択・実機受入）。
- 根拠: 2026-11-25の着手指示、既存Mini素材を参考にする追加指示、M04の実装候補から引き継いだ受信条件。
- 今回の区切り: Miniの仕草にならい、回答待ちに顎に指を添えて小さく動く姿勢を追加。ユーザーがGitから取得して実機確認する。
