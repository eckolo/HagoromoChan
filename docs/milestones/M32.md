# M32 会話履歴のブックマークと呼び出し

- 目的: あとで読み返したい発言に目印を付け、履歴をさかのぼらず再参照できるようにする。
- 対象: 個々の保存済み発言のブックマーク設定・解除と保持、ブックマークの一覧または呼び出し、対象の表示と速やかな閉じ方。
- 方針: ブックマークした履歴カードを通常の履歴に常駐させない。購読窓のボタンから、既存履歴に重ねる一時的な「思い出す窓」を開く案を優先して検討する。専用窓を使う場合も一操作で閉じ、元の表示に戻れること。操作位置や見せ方は着手時に確定する。
- 対象外: 通常履歴を削除・固定表示すること、新着判定の変更、通信やクラウド取り込みの変更。
- 依存: M03の会話履歴、M14の新着判定を維持。M26の自動非表示とM18の会話別履歴との整合は設計時に確認するが、初版のローカル履歴でのブックマークをそれらの完成待ちにはしない。購読窓のボタンはM06の簡易表示と競合しないようにする。
- 作業ブランチ（予定）: `milestone/M32-history-bookmarks`。
- 承認根拠: 2026-11-27 JSTのユーザー指示、[MGMT-31](MGMT-31.md)。
