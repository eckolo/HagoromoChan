# M21 キャラクターアクションの順番制御・中断制御・終了演出

## 定義

- 目的: アクションが途中で切れるのを避け、終了時にも自然な反応が見えるようにする。
- 対象: 有限アクションの待ち行列、カーソル追従など継続アクションとの切り替え、通常終了時の専用演出。
- 対象外: M10の自律移動、M33の状況別アクション選択、M22の吹き出し座標、強制終了時の演出保証。
- 依存: M09の反応基盤、M08の正常終了経路。既存のM09・M08の受入状態は変更しない。
- 作業ブランチ（予定）: `milestone/M21-action-sequencing`。
- 優先度: 他項目との相対順位は着手時に確認。
- 分岐元 main SHA: `82a75eec6af011771b0c1f94213e41e024a7479a`。
- 担当: AI（着手後）、ユーザー（見た目・動作の受入）。
- 承認根拠: 2026-11-26 ユーザーの追加要望・MGMT-23。
