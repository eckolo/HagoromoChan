# M19 他会話への発言送信

## 定義

- ID: M19
- 優先度: 高
- 目的: M05で回答を受信して登録された既存のクラウドChat／WorkをM18のUIで選択し、その会話に追加の質問・指示を送信して対応する回答を受け取れるようにする。
- 対象範囲: 受信元と同じ会話への公開手段による発言送信、送信可能性・許可の明示、送信時の対象スレッド確定、要求と結果／返信の関連付け、スレッド単位の送信待ち・返信待ち、複数会話の並行操作、誤配送・重複送信防止、受信経路との結合。取得した返信先情報の妥当性を確認し、送信先をタイトルだけで決めない。
- 対象外: ローカルWork、未受信会話の検索・自動列挙、新規会話作成・プロジェクト選択、Workの汎用実行管理・中断・承認代理、過去履歴の同期、M06の汎用障害復旧、M18の切替UIの全面改修。
- 依存 ID・着手条件: M05、M18。先行M05で送信先識別・利用可能性を調査し、M19の着手時に最新公開仕様と実アカウントで確認する。両先行IDの契約を利用し、main統合後に送受信・UIの結合を検証する。
- 作業ブランチ（予定）: `milestone/M19-cloud-conversation-send`
- 分岐元 main SHA: 未着手・枝未作成。
- 担当: AI（着手後）、ユーザー（送信権限・実アカウント確認、受入）。
- 承認根拠: 2026-11-26のユーザー承認・MGMT-17。
