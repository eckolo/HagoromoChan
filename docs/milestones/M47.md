# M47 履歴の未読アイコン配置と新着からの返信導線

## 定義

- 目的: 履歴画面で未読の操作を探しやすくし、すべての会話窓を閉じた状態で新着を受けた直後にも、窓を閉じ直したり右クリックメニューを開いたりせず返信できるようにする。
- アイコン配置: 履歴の窓右上に並ぶ操作のうち、未読の発言で表示する「既読にする」アイコンをグループの最左端に置く。未読以外での表示条件、ボタンの意味、他のアイコンの相対順は維持する。接続状態窓の「新着」ボタンの移設は対象外。
- 新着から返信: 入力窓が閉じていて履歴が表示されている場合は、最下部の操作窓に「話しかける」アイコンを置く。アイコン一回で入力窓を開き、入力に移れる。履歴カード内には追加せず、受信だけで入力窓を開かない。すでに開いている入力窓、既存の下書きと選択中の履歴は保持する。最下部の操作窓に置くアイコンの形や狭い画面での収まりは着手時に設計する。
- 対象外: 新着を自動既読にすること、実際の送信や別会話への送信（M19）、キャラクター演出（M41）。M18の複数会話切替が入る場合は返信対象を取り違えないよう整合を確認する。
- 依存: M03の基本UI、M14の新着解除（いずれも完了）。スクロールは M35 のネイティブ長文表示および M28 の書式付き履歴と整合させる。他会話機能は現行の通常会話での改善の着手条件としない。
- 作業枝（予定）: `milestone/M47-unread-and-reply-controls`。優先度は着手時に確認。
- 承認根拠: 2026-11-28 JST ユーザーの追加要望、[MGMT-46](MGMT-46.md)。最下部の操作窓を使う決定は [MGMT-48](MGMT-48.md)。

## 頭上窓の「新着」から開く履歴

[MGMT-48](MGMT-48.md) による追加。頭上の通知・状態窓で利用者が「新着」を押した場合を対象とする。選択時点の同じ会話の新着と履歴表示を基準に、優先度は次の順とする。

1. 最も古い新着を必ず開き、本文の読み始めを画面内に出す。長文全体を一画面に収める必要はなく、既存のスクロールで続きが読めること。
2. その条件の下で、実際に画面内に表示できる新着をできるだけ新しい方まで見せる。履歴の時系列や通常の前後移動は崩さない。
3. 上の二つを同じように満たす配置のうち、選択前に見えていた履歴カードや本文の位置をなるべく保つ。最古の表示カードが新着より古いというだけで、それより古い窓を一律に畳んだり閉じたりしない。空間を確保するための変更は許容するが、入力窓・下書きは維持する。

選択で実際に表示された新着をどう既読にするかはM14の既存ルールに従い、画面外を一括で既読にしない。受信による自動表示にはこの操作を適用しない。配置の評価は既読反映前の新着を基準にし、同じ操作中に基準を入れ替えない。

## 履歴カードの出入りを優先するスクロール

[MGMT-50](MGMT-50.md) による追加。対象は履歴のスクロール操作であり、「新着」選択時の初期配置や入力欄のスクロールは変えない。

- 複数の履歴カードが見えていて、操作方向にカードの表示・非表示を切り替えて履歴を進められる場合は、それを優先する。ポインターが短い履歴上・部分表示された長い履歴の本文上のどちらでも、同じ方向・同じ配置なら同じ履歴移動にする。長いカードが画面の上側・下側のどちらにあっても適用する。
- 例: 長い履歴が下側に部分表示されているとき下へ送ると、長い本文の位置だけを動かすのではなく、上のカードを表示範囲から外して長い履歴の表示領域を広げる。長い履歴が上側にある場合も、下へ送る操作を本文上で行っただけで履歴移動が抑止されてはならない。逆方向の移動も同じ優先規則。非表示は一時的な表示状態であり、履歴の削除や既読化ではない。
- 履歴の表示・非表示による移動がその方向にできず、1件の履歴が画面内の履歴に使える高さを占める場合に限り、そのカードの長文本文を内部スクロールする。平文・書式付きで優先順位をそろえ、先頭・末尾への到達と逆方向への移動を保つ。実際に表示されたカードだけを扱う M14 の判定、原文・全文コピー、入力欄と下書きは維持する。
