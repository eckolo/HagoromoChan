# M47 履歴の未読アイコン配置と新着からの返信導線

## 定義

- 目的: 履歴画面で未読の操作を探しやすくし、すべての会話窓を閉じた状態で新着を受けた直後にも、窓を閉じ直したり右クリックメニューを開いたりせず返信できるようにする。
- アイコン配置: 履歴の窓右上に並ぶ操作のうち、未読の発言で表示する「既読にする」アイコンをグループの最左端に置く。未読以外での表示条件、ボタンの意味、他のアイコンの相対順は維持する。接続状態窓の「新着」ボタンの移設は対象外。
- 新着から返信: 第一候補は新着時の履歴だけを非アクティブで表示し、そこから「話しかける」を直接一操作で開いて入力に移れる形。入力窓も自動で開く案は比較対象とし、入力フォーカスや画面を不用意に奪わない方を優先する。既存の下書き・閲覧中のカードと、すでに開いている入力窓を保持する。
- 対象外: 新着を自動既読にすること、実際の送信や別会話への送信（M19）、キャラクター演出（M41）。M18の複数会話切替が入る場合は返信対象を取り違えないよう整合を確認する。
- 依存: M03の基本UI、M14の新着解除（いずれも完了）。他会話機能は現行の通常会話での改善の着手条件としない。
- 作業枝（予定）: `milestone/M47-unread-and-reply-controls`。優先度は着手時に確認。
- 承認根拠: 2026-11-28 JST ユーザーの追加要望、[MGMT-46](MGMT-46.md)。どちらの表示方式にするかは着手時に確定する。

## 頭上窓の「新着」から開く履歴

[MGMT-48](MGMT-48.md) による追加。頭上の通知・状態窓で利用者が「新着」を押した場合を対象とする。選択時点の同じ会話の新着と履歴表示を基準に、優先度は次の順とする。

1. 最も古い新着を必ず開き、本文の読み始めを画面内に出す。長文全体を一画面に収める必要はなく、既存のスクロールで続きが読めること。
2. その条件の下で、実際に画面内に表示できる新着をできるだけ新しい方まで見せる。履歴の時系列や通常の前後移動は崩さない。
3. 上の二つを同じように満たす配置のうち、選択前に見えていた履歴カードや本文の位置をなるべく保つ。最古の表示カードが新着より古いというだけで、それより古い窓を一律に畳んだり閉じたりしない。空間を確保するための変更は許容するが、入力窓・下書きは維持する。

選択で実際に表示された新着をどう既読にするかはM14の既存ルールに従い、画面外を一括で既読にしない。受信による自動表示にはこの操作を適用しない。配置の評価は既読反映前の新着を基準にし、同じ操作中に基準を入れ替えない。

## 完了条件（暫定）

| ID | 条件 | 確認方法 |
| --- | --- | --- |
| AC-01 | 未読の操作アイコンが右上グループ内で最左端。他のアイコンの順序、非表示条件、既読操作は従来どおり。 | 通常・狭い配置および未読／既読のWindows描画 |
| AC-02 | 会話窓を閉じて新着を受け、履歴から追加一操作以内で話しかけ窓で入力できる。閉じ直しや右クリックメニューを要しない。 | 新着前に両窓が閉じた状態からWindows実機 |
| AC-03 | 受信だけで作業中のフォーカスを奪ったり未読を解除したりしない。履歴表示位置、会話先、保存済みの下書き・送受信を壊さない。 | フォーカス、下書き保持、履歴のみ／入力済みの回帰 |
| AC-04 | 頭上窓の「新着」で、最古の新着を読める状態にし、同時に見せられる範囲では新しい新着を優先。同条件の配置なら以前の表示を最も多く残す。表示できる古いカードを一律に閉じない。 | 選択前の古いカード、新着の間に既読の発言がある場合、長文と狭い窓、複数の候補が成立する場合を共通描画テストとWindows実機で確認 |
