# M35 長文の会話窓の高さ調整と全文表示

- 目的: 長い本文が下端で切れて読めなくなる事象を解消する。
- 対象: 送信済みの自分の発言・返信の吹き出し（現在表示と履歴送り）、未送信の長い入力も同じ問題があれば対象。本文が画面内で収まる場合は実際の改行・フォント・表示倍率と枠を含めて必要な高さへ伸ばす。
- 画面の作業領域を越えるときは窓を画面外に広げず、ページ送りまたは本文内スクロールで末尾を読めるようにする。履歴の発言送りと表示操作が競合しないこと。開いている窓や他の項目を不用意に変更しない。
- 依存: M03の会話窓、M22で確認済みの左右位置・吹き出し幅・折り返し。M22の完了マージや履歴を変更しない。
- 対象外: 発言データ・会話通信の変更、M21の動作演出、一般のMarkdown対応。
- 作業枝: `milestone/M35-bubble-text-fit`。
- 承認根拠: 2026-11-27 JST、長い発言が下にはみ出したとの実機報告と修正依頼。[MGMT-36](MGMT-36.md)。
