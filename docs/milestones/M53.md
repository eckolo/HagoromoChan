# M53 有限モーションが短い押下で途切れる不具合を修正

## 定義

- 目的: 手振りなど終点がある動作の再生中に、同じ操作を短く押し直しても絵が静止姿勢に飛ばず、最初の動作が終点まで続くようにする。
- 対象: キャラクター上の短い押下・解放による表示の切れと、後続動作の共通再生。確認済みの簡易再現では、キューの順序ではなく押下中に静止姿勢を表示することが途切れを生んだ。
- 対象外: M41の新しい演出、M33の自動選択・待機速度、ドラッグ・長押し・動作OFF・通常終了の仕様変更、新規作画。
- 依存: M21のフェーズ・順番制御（完了）。M41とは同じ再生箇所の結合回帰を行うが、別マイルストーンとする。
- 作業枝（予定）: `milestone/M53-finite-motion-continuity`。実装着手時に最新mainから作る。
- 承認根拠: 2026-11-28 JST の利用者報告と採番指示、[MGMT-52](MGMT-52.md)。

## 共通再生モデル（MGMT-54）

- 既存のフェーズ制御を土台に、変わらないモーション定義と、再生中の位置・状態を持つインスタンスを分離する。静止・表情・ループ・追従・有限動作を同じ契約で表す。定義にはフレーム／区間とその表示データ（素材・姿勢・変形等）、継続時間、反復・終点、切替可能境界または中断不可区間をまとめる。入力契機からの対応付け、再生順・中断判定、描画は分離する。
- 再生器は定義上の現在フレームと切替境界に従い、境界に達するまでは通常の操作・後続要求で別の絵や静止姿勢に切り替えない。時計を止める必要がある場合も同じフレームを保ち、再開は続きから。アプリ終了の期限や描画不能、明示した動作OFFなど、動作継続より優先すべき例外はポーズ別に分けず共通方針で扱う。クリック処理やメニュー表示は演出完了を待たせない。
- 共通判定は境界の直前・境界上・直後、同種／別種の要求、保留・再開、終了・動作OFFを代表定義で検証。全定義の時間・区間・切替境界と使用素材は機械的に検査する。新規演出は原則として定義・素材の追加と入口の配線だけとし、共通再生器に動作名の分岐を足さない。実画面では各入口と見え方を確認するが、全動作同士の総当たりを前提にしない。
