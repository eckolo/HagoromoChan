# M33 状況に応じたキャラクターアクションの選択

- 目的: 同じイベントで同じ仕草を固定反復したり、意味なくランダムに選んだりせず、状況に合った変化を出す。
- 対象: 既存のアクション制御用フラグを構造化したSSPの「状態」、イベントに意味の合う複数候補と直近の動作を踏まえた選択、行動しないという選択肢。
- 設計候補: 必要最小限の状態と実行可能な候補を専用のChatGPT Work等へ渡し、今取るべきアクションの提案を受け取る。連携方法・呼び出し頻度・状態の粒度は未確定。実現性を調査し、ローカルルールのみの案とも比較する。
- 分界: M21は再生・中断の制御、M10は移動の実行と境界・ユーザー操作の保護。移動を候補に含める設計はM10と調整し、統合・検証はM10の移動基盤を前提とする。移動以外の設計をM10待ちにする必要はない。
- 制約: 提案を受けてもSSP側が現時点の状態・候補・中断可否を再確認する。古い応答、通信失敗、無効な提案、動作OFF・操作中・終了時は既存のローカル動作または見送りに戻す。会話本文、窓タイトルや中身は選択の入力に含めない。実装・Work作成・外部送信は今回行わない。
- 追加候補（[MGMT-40](MGMT-40.md)）: 履歴の高速スクロールや複数の返信待ちが重なったときに、混乱・目が回る表情や動作を選べるようにする。発動条件と解除、連発防止を設計し、閲覧や入力を止めない。まず既存素材・描画で成立するかを確認し、新規作画が必要なら原則 Work に任せる。動作の再生と中断は M21 の共通制御に従う。起動時の固定ジャンプは M41 に分離する。
- 待機モーション調整（[MGMT-49](MGMT-49.md)）: 通常待機の瞬きと回答待ちの思案モーションが速く見えるため、現行よりゆったりしたテンポへ調整する。各動作の再生時間と、次の動作までの静止時間を別々に比べ、瞬きの閉じ・開きや思案の戻りが不自然に間延びしない組合せを選ぶ。全アニメーションの一律減速はしない。既存素材を先に試し、Work連携・自律移動・M41を待たずに取り組める。
- 調整時の境界: M21の共通フェーズと自然な中断点を維持する。伸ばす静止区間では着信などに譲れるようにし、入力、ドラッグ、動作OFF、通常終了、回答受信後の状態切替を遅らせない。
- 作業ブランチ（予定）: `milestone/M33-contextual-action-selection`。
- 承認根拠: 2026-11-27 JSTのユーザー指示、[MGMT-34](MGMT-34.md)。
