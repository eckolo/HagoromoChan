# M03 羽衣ちゃんの表示・ウィンドウの見た目の調整

## 定義

- ID: M03
- 優先度: 最高
- 目的: SSP や Mini のように、デスクトップ上の羽衣ちゃんが吹き出しで話し、羽衣ちゃんにメッセージを入力して会話を継続できる自作 UI にする。アプリの必須機能として最優先で進める。
- 対象範囲（初期案）: キャラクター表示、会話の吹き出し、入力と既存の Dot 返信経路の UI 接続、ウィンドウ外観と通常操作。
- 対象外: Dot の自発発言、他会話接続、通信状態の詳細化、自動起動（M08）、反応アクション（M09）、自律移動（M10）。
- 依存 ID: 技術依存は未確定。
- 着手条件: 最優先。ほかのアプリ本体マイルストーンより先に基本 UI を実用段階へ進める。
- 作業ブランチ: `milestone/M03-character-and-window-ui`
- 分岐元 main SHA: `41801b9720ac96e2c852c6b292ae86aea6491e39`。
- 担当: AI。
- 根拠: 2026-11-25 のユーザー提示のマイルストーン一覧。2026-11-25 の画面設計案への方向性承認に基づき設計実装する。
