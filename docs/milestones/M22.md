# M22 会話吹き出しの本文枠の位置合わせ・長文表示

## 定義

- 目的: 吹き出しの向きが変わっても、飛び出した飾りを除く枠の位置が意図せず横にずれず、長文でも画面に収まらない最終行を見切れさせない。
- 対象: 左右向き共通の本文枠アンカー、飾り専用領域、DPI・画面端での配置確認、本文枠の実表示高に応じた長文ページ分割の修正。
- 対象外: 飾りの廃止、本文データや入力操作の仕様変更、M18の会話切り替え、M21の演出。
- 依存: M03の会話UI。M03の受入状態は変更しない。
- 作業ブランチ（予定）: `milestone/M22-bubble-body-alignment`。
- 優先度: 他項目との相対順位は着手時に確認。
- 分岐元 main SHA: 未着手。枝は着手時に作成。
- 担当: AI（着手後）、ユーザー（見た目・動作の受入）。
- 承認根拠: 2026-11-26 ユーザーの追加要望・MGMT-23。
