# M18 複数会話スレッドの切り替えUI

## 定義

- ID: M18
- 優先度: 高
- 目的: 既存の羽衣ちゃんとの会話とM05で受信・登録されたクラウドChat／Workの会話を、同一アプリ内で横方向に切り替えて閲覧・操作できるようにする。
- 対象範囲: スレッド切替の窓操作UI（横方向の移動、スレッド一覧等の具体方式は設計時に決定）、選択中の会話種別・タイトル等の識別表示、同一スレッド内の既存の縦方向履歴操作、スレッドごとの履歴・新着表示、選択状態と入力先の整合、新着による切替を強制しない表示設計。既存Dotの会話入力・送受信は維持し、M19未実装の会話には入力・送信可否を明示する。
- 追加対象: 通常起動直後に既存の羽衣ちゃんとの会話の入力窓が隠れ、話しかけるたびに開き直す手間があるとの利用者報告。起動直後に手動で窓を出し直さず入力を始められるようにする。意図的に閉じる従来の操作と履歴表示は維持する。原因の特定、起動時設定や表示状態の復元方式は着手時に確認する。
- 対象外: クラウド連携による回答取得・登録（M05）、他会話への発言送信（M19）、ローカルWork、未受信会話の検索・新規会話作成、通信障害復旧（M06）、新着解除ルール自体の変更（M14）、キャラクターアクションの追加（M09）。
- 依存 ID・着手条件: M03・M05。M05の会話管理・受信参照契約を確定してから本実装し、M05のmain統合後に結合・統合する。M09の表示・演出、M14の新着管理との整合を確認する。M19の完了は条件としない。
- 作業ブランチ（予定）: `milestone/M18-conversation-switching-ui`
- 分岐元 main SHA: 未着手・枝未作成。
- 担当: AI（着手後）、ユーザー（UI方針・実機受入）。
- 承認根拠: 2026-11-26のユーザー承認・MGMT-17。
