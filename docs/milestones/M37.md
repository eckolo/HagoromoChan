# M37 羽衣ちゃんのイラストの髪の隙間の透過修正

- 目的: 髪束の間に残った白い背景を透過し、濃色の背景で見えてしまう白抜けを直す。
- 対象: 羽衣ちゃんSSPの現用・切替可能・保守対象の立ち絵、表情差分、アクション画像・スプライトと対応する編集元。原画寄り・デフォルメなどの版、素材パックや共有素材の流用元を照合する。入手不能や用途未確認の素材は、確認済みと混同せず一覧に残す。
- 作業: 使われる素材・派生・全コマを列挙し、色だけで判定せず透過表示と濃淡2種以上の背景で実見する。漏れのあるイラストをすべて、ファイル／版・コマ／ポーズ・具体的な位置とともに一覧にする。その対象だけ修正して派生素材に反映する。
- 制約: 髪のハイライト・目・白い衣装等を白色という理由で消さない。輪郭の自然な縁、寸法・コマ順・基準位置を保持。利用者のローカル差し替えは勝手に変更しない。
- 作業ブランチ（予定）: `milestone/M37-hair-gap-alpha`。
- 承認根拠: 2026-11-27 JSTのユーザー指示。[MGMT-38](MGMT-38.md)。
