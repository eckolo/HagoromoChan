# M29 画像ファイルの送受信

- 目的: SSP から画像ファイルを送り、相手から受け取った画像を会話内で確認できるようにする。
- 対象: ファイル選択・添付送信、受信・表示または開く操作、失敗表示と再試行。まず通常の SSP と羽衣ちゃん間で送信・受信の可否を別に調査する。
- 対象外: 画像生成・編集、外部への自動共有。画像以外のファイル、クラウド Chat／Work からの添付の取得・送信は、対応範囲と連携経路が確認できるまで保証しない。
- 依存: M03 の履歴・入力 UI、M04 の送受信。M05／M19 の外部会話経路へ広げる場合はそれぞれ別に連携条件を確認する。
- 作業ブランチ（予定）: `milestone/M29-image-attachments`。優先度は着手時に確認。
- 承認根拠: 2026-11-26 JST のユーザー追記、MGMT-25。

## 完了条件（暫定）

- AC-01: ユーザーが選んだ画像を、意図した会話に添付して送信できる。
- AC-02: 受信した画像を正しい会話・発言との対応を保って表示または開ける。従来のテキストの送受信を壊さない。
- AC-03: 未対応形式・容量超過・失敗は利用者に分かり、再試行で重複しない。添付の検証・アクセス制限を確認し、ファイルの自動実行や意図しない外部公開を行わない。

- 未確定: 対応形式・容量・保存と削除のルール、送受それぞれの接続手段、画像以外のファイルの扱い。
- 開発状態: 未着手。実行状態: 停止中。作業枝未作成。次は送受それぞれの対応経路の確認（羽衣ちゃん、着手指示後）。
