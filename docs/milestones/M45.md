# M45 自動テストの共通実行基盤

## 定義

- 優先度: 最優先。
- 目的: 個別マイルストーン専用の起動手順ではなく、共通の `scripts/Test.ps1` から現行ソースの自動テストを一貫して実行できるようにする。
- 対象: テスト名の管理、共通起動・一覧・絞り込み、独立したテストの継続、結果集計、README の利用手順。
- 対象外: アプリ本体の機能修正、マイルストーンごとの専用起動手順、利用者の実データや通常起動中のプロセスの操作。旧版を固定した M14 の手動検証は現行回帰へ移せる範囲を整理し、前提が必要なものは別途明記する。
- 依存: MGMT-44。M35 の長文表示修正には依存せず、M35 側は統合後の共通基盤を利用する。
- 作業枝: `milestone/M45-shared-test-runner`。
- 承認根拠: 2026-11-27 の利用者指示。テストコードとスクリプトを見直し、現時点で大きな変更なら最優先として分ける。
- 仕様確定: 無指定で全件実行。 `-TestName` に一覧のIDを1件指定すると、その検査だけを実行する。除外指定は扱わない。
