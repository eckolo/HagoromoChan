# M27 会話履歴窓・入力窓の背景透過

- 目的: 会話履歴窓と「話しかける」入力窓の背景を少し透過させる。透過率を調整できる設定での実現も可。
- 対象: 履歴窓と入力窓の見た目。背景層を対象とし、文字、カーソル、選択、ボタンに窓全体の透過を掛けない。既存のマスコット表示・窓の配置・入力操作は変えない。
- 対象外: M22 の本文枠位置と改ページ、新着または履歴寿命、通信・保存データの変更。
- 依存: M03 の履歴・入力 UI。M22 と共有する表示箇所は回帰を確認し、仕様・受入を混ぜない。
- 作業ブランチ（予定）: `milestone/M27-conversation-window-opacity`。優先度は着手時に確認。
- 承認根拠: 2026-11-26 JST のユーザー指示、MGMT-25。

## 完了条件（暫定）

| ID | 条件 | 確認方法 |
| --- | --- | --- |
| AC-01 | 背景だけが軽く透過し、会話履歴と入力窓の双方で文字・操作部品が読み取れ、フォーカスやマウス操作は従来どおり。 | Windows の実画面、明暗の異なる背景と既存の入力操作 |
| AC-02 | 透過率を設定にする場合は、設定が試せ、再起動後も値が保持される。固定値の場合は既存の表示を壊さない程度であることを確認する。 | 設定の変更・再起動、または固定値の見た目比較 |
