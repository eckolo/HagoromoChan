# M41 アプリ起動とキャラクター操作時のアクション

## 定義

- 目的: アプリの起動・終了と、常駐キャラクターを操作したときの反応を見分けられるようにする。
- 対象: 通常のSSP起動、キャラクターの右クリックでメニューを開いたとき、キャラクターの左クリックで会話窓を開いたとき・閉じたとき。四つの契機を別に定義する。
- 起動・右クリック: 着信ジャンプなどの既存モーションを優先候補とし、意味が伝わるか、新規動作が必要かを設計時に比較する。起動は表示準備完了後に一度だけ。右クリックでメニューが開く操作を待たせない。
- 窓の開閉: キャラクタークリックで実際に開いた・閉じたときに、それぞれアプリ起動・終了とは異なる演出を新設する。自動受信による表示、別の入力ボタン、ドラッグ、表示再配置だけではこの演出を再生しない。演出を新設することと、新規作画が必要かは別に判断する。
- 制約: 動作OFF、入力・ドラッグ優先を守り、着信・メニュー・終了との競合はM21の共通フェーズ制御で解決する。抑止中にイベントを無制限に積まず、入力や実際の終了を待たせない。自動起動・再起動に適用する条件は着手時に確認する。
- 対象外: 起動方式変更、アプリ終了の演出の作り直し、M33の状況別選択、M47の窓操作UIそのもの。新規作画が必要なら原則 Work に任せる。
- 依存: M03（操作）、M08（起動・終了）、M09（既存素材・反応）、M21（共通制御）は完了済み。M47とはクリック・自動表示・入力ボタンの境界を確認するが、一律の着手待ちとはしない。
- 作業枝（予定）: `milestone/M41-startup-reaction`（既存名を維持）。優先度は着手時に確認。
- 承認根拠: 当初登録 [MGMT-40](MGMT-40.md)、2026-11-28 JST の追加要望 [MGMT-46](MGMT-46.md)。

## 演出の候補と実装順（MGMT-54）

- 起動: お辞儀を第一候補にし、目線だけを下げる動作と区別できるよう、上体も沈んで戻る案を比較する。初回表示の準備ができてから一度、リレー接続・履歴同期とは独立。
- 右クリック: 手前に出たメニューを短くのぞき込む案。メニューは即時に開き、開いている間に反応が見えることを確かめる。閉じるまで演出を保留して後から流さない。
- 会話窓を開く: 「何か御用？」と少し不思議そうな首かしげを第一候補にする。実際にキャラクタークリックで開いたときだけ。
- 会話窓を閉じる: 専用の反応。起動のお辞儀・終了のお別れ・開く反応とは区別し、具体的な動きは未決定。閉じる操作の既存対象・境界は維持。
- 演出案・既存素材の検討は並行可能。製品での再生実装は [M53](M53.md) の共通契約を利用し、その基盤を先に検証・統合する。M41は入口と定義・素材を加え、動作ごとの中断ロジックを持たない。新規作画は既存素材で違いを出せない場合に限って検討する。
