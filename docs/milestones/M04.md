# M04 Dotからの能動的な発言

## 定義

- ID: M04
- 優先度: 高（2026-11-25、ユーザー指示により中から変更）
- 目的: Windows アプリからの質問に対する返信だけでなく、Dot が自ら送った発言をアプリで受けられるようにする。
- 対象範囲（初期案）: 既存の返信とは別に、自発的な発言を受け取る経路と表示、必要な記録の設計・検証。
- 対象外: 公式 Dot 会話の全履歴の自動同期、他会話アクセス。
- 依存 ID: 技術依存は未確定。
- 着手条件: M03・M08の完了を受け、次の高優先度候補。M09と並行着手可能な候補とし、その完了を必須条件にしない。各作業の開始は別途指示後。
- 作業ブランチ: `milestone/M04-dot-proactive-messages`
- 分岐元 main SHA: `78671596e4d90bffe3446af930182fa85ac4e966`。
- 担当: 本会話（AI・設計実装）、ユーザー（実機・権限確認、M09担当間の調整）。
- 根拠: 2026-11-25 のユーザー提示のマイルストーン一覧。詳細仕様・完了条件は初期案として着手時に確定する。
