# M04 Dotからの能動的な発言

## 定義

- ID: M04
- 優先度: 高（2026-11-25、ユーザー指示により中から変更）
- 目的: Windows アプリからの質問に対する返信だけでなく、Dot が自ら送った発言をアプリで受けられるようにする。
- 対象範囲（初期案）: 既存の返信とは別に、自発的な発言を受け取る経路と表示、必要な記録の設計・検証。
- 対象外: 公式 Dot 会話の全履歴の自動同期、他会話アクセス。
- 依存 ID: 技術依存は未確定。
- 着手条件: M03・M08の完了を受け、次の高優先度候補。M09と並行着手可能な候補とし、その完了を必須条件にしない。各作業の開始は別途指示後。
- 作業ブランチ: `milestone/M04-dot-proactive-messages`
- 分岐元 main SHA: `78671596e4d90bffe3446af930182fa85ac4e966`。
- 担当: 本会話（AI・設計実装）、ユーザー（実機・権限確認、M09担当間の調整）。
- 根拠: 2026-11-25 のユーザー提示のマイルストーン一覧。詳細仕様・完了条件は初期案として着手時に確定する。

## 採用候補 v1.0

[設計](../design/M04-proactive-messages.md) に従い、独立したMCP send_message、名前空間付きID、既存schema v2での保存、既存ポーリング・新着機構の利用と履歴見出しによる区別を実装候補として作成した。追加回帰4件を登録。M09の会話・マウス制御ファイルには書き込まない。公式Dotの自発的調査による直接書き込み制約を確認し、手動の明示ツール呼出しと承認済みタスクでの無人実行検証を分ける。クラウド側メタデータ・権限・購読の変更は実施しない。

## 未確定事項

発言の種類、通知・履歴の詳細、PC 不在時の扱い、承認・配送条件は未確定。既存replyはrequest_idに紐付く回答専用であり、対応質問なしの発言は別経路とする案を調査する。自発発言ID、重複防止、永続化、既存の返信・outboxとの区別、Dotからの実際のツール呼出し可能性を検討する。M09との調整案として、Desktopが新規の受信済み発言を確定した際の中立的な通知境界を設計する。アニメーションや素材の管理はM09の責務とし、M04から直接演出を制御しない。初回履歴読込や重複再取得を新着イベントとしない条件を両IDで整合させる。
