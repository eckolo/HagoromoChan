# M43 履歴の発言ごとの折りたたみ表示

## 定義

- ID: M43
- 優先度: 着手時に確認。
- 目的: 長いログや本文が、その後の履歴閲覧を占有しないようにする。
- 対象範囲: 保存済み履歴の発言ごとに、本文の冒頭を表示上約3行に折りたためるようにする。必要なときは同じ発言を展開して末尾まで読め、また折りたためる。幅・フォントに応じた表示行で判断し、約3行以内の短文は無理に縮めない。
- 仕様未確定: 初期の折りたたみ状態、状態を次回起動まで保持するか、操作ボタンの置き場所。初期状態で新着を見落とさないことと、後の閲覧で長文が邪魔にならないことを両立する案を着手時に決める。
- 対象外: 入力欄の折りたたみ、本文の削除・短縮保存、送受信変更。M26の時間による非表示、M32のブックマーク、新着判定とは別。
- 依存 ID・着手条件: M03の履歴UI、M22/M35の高さ・枠・全文表示と整合する。M28の書式化は将来の整合確認とし、初版の必須条件にはしない。
- 作業ブランチ（予定）: `milestone/M43-history-message-collapse`。未作成。

- 承認根拠: 2026-11-27 JST のユーザー指示、[MGMT-42](MGMT-42.md)。

## 挙動の改訂案（2026-11-27 JST、実装前）

発言ごとに折りたたむ。ソースの本文、全文コピー、新着・既読の規則、入力欄を変えない。現在の変更は設計のみ。

| 場面 | 挙動 |
| --- | --- |
| 最新側の保護範囲 | 最新位置の履歴窓を基準に、最新から古い方向へ、見出しと間隔も含めて収まる連続範囲を求める。原則は展開時の高さ。ただし、判定直前の保護範囲に属し、かつ手動で折りたたんでいるカードだけ、折りたたみ時の高さで数える。この範囲は自動折りたたみの対象外。収まらないカードを飛ばさない。最新1件が長すぎるときも最新1件を保護し、展開時の欄内スクロールを残す。「新着」から明示的に開く対象は範囲外でも展開できる。 |
| 展開 | 折りたたんだ発言の本文・見出し・背景のうち、機能ボタンやリンク等を除く場所で左クリック（押して離す）すると展開。「全文を表示」ボタンでも展開でき、キーボード操作とアクセシブルな名前を保持。文字選択のドラッグ、右クリック、ホイール、コピー・既読ボタンの操作は展開にしない。展開時は文頭に着地。 |
| 折りたたみ | 表示中の手動操作は「折りたたむ」ボタンだけで、保護範囲でも優先する。範囲外の長文は既定で折りたたみ。展開した範囲外の発言は表示カード一覧から外れたとき、または履歴窓を閉じたときに自動で折りたたむ。画面に残っている発言は、新着やサイズ変更で保護範囲から外れてもその場では閉じない。フォーカス喪失、別の窓による遮蔽、レイアウト途中の一時的な除外では閉じない。 |
| 行数 | 既存の設定画面に「履歴の折りたたみ行数」を追加。既定3行、2～5行の整数案。設定値だけを既存の設定に保存し、次回起動にも引き継ぐ。折りたたみ中の表示に反映し、展開中の発言は開いたまま。実際に折り返した表示行で判定する。指定行数以内の本文には開閉操作を出さない。狭い枠は完全な行だけを表示し、枠外に出さない。 |
| 移動と位置 | 開閉で表示位置の基準となる発言を変えない。折りたたみ中の矢印・ホイールは発言間を移動。展開中は本文をスクロールし、端で発言間へ進む。開閉時のレイアウト変化だけで入力フォーカスを奪ったり、既読にしたりしない。 |
| 保存の境界 | 行数だけを設定として保持。手動で折りたたんだ保護範囲の発言はアプリ起動中はその選択を尊重し、明示的に展開するまで勝手に開かない。開閉状態は履歴DBや設定に保存しない。全文コピーはどちらでも原文。 |

保護範囲は、手動の開閉・新着・安定した窓サイズ変更・表示範囲外への移動などで自動判定が動くたびに計算する。判定の開始時点で、直前に確定した保護範囲と、操作反映後の手動開閉状態を固定して一度だけ計算する。新たに範囲に入ったカードや自動で折りたたまれたカードを、その回の計算に戻して再判定しない。初回は展開時の高さを使う。この計算だけで手動の開閉を上書きせず、表示中の発言は範囲外へ移っても、その場で閉じず実際に表示から外れた時に閉じる。履歴単独の最新位置を基準とし、閲覧位置や入力欄の一時的な開閉には左右されない。

設計上は、クリックの対象と、確定後の表示カードから外れた事実を別に扱う。本文をドラッグできるよう通常のクリックとドラッグを区別し、ネストした既存ボタンの操作を優先する。表示範囲の判定はレイアウトが確定した後に行い、同じレイアウト処理中に開閉状態を往復させない。スクロール先・展開・既読は別の状態として扱う。展開時は既存のネイティブ履歴描画とスクロールを再利用する。

共通の自動テストでは短文・改行・長文・絵文字、幅と行数の変更、クリックとドラッグ／ボタンの区別、複数件が収まる保護範囲と最新1件が画面を使い切る場合、手動折りたたみで保護範囲が広がる例と手動展開で戻る例、自動で折りたたんだ高さで対象が連鎖的に広がらないこと、画面に残るカードの保持、範囲外から戻ったプレビュー、末尾到達、原文コピーと既読・入力欄の非回帰を確認する。行数設定の再起動後保持も検証し、実際の描画はWindowsで確認する。作業番号を含むアプリ識別子や専用テスト入口は設けない。
