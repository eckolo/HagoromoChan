# M43 履歴の発言ごとの折りたたみ表示

## 定義

- ID: M43
- 優先度: 着手時に確認。
- 目的: 長いログや本文が、その後の履歴閲覧を占有しないようにする。
- 対象範囲: 保存済み履歴の発言ごとに、本文の冒頭を表示上約3行に折りたためるようにする。必要なときは同じ発言を展開して末尾まで読め、また折りたためる。幅・フォントに応じた表示行で判断し、約3行以内の短文は無理に縮めない。
- 仕様未確定: 初期の折りたたみ状態、状態を次回起動まで保持するか、操作ボタンの置き場所。初期状態で新着を見落とさないことと、後の閲覧で長文が邪魔にならないことを両立する案を着手時に決める。
- 対象外: 入力欄の折りたたみ、本文の削除・短縮保存、送受信変更。M26の時間による非表示、M32のブックマーク、新着判定とは別。
- 依存 ID・着手条件: M03の履歴UI、M22/M35の高さ・枠・全文表示と整合する。M28の書式化は将来の整合確認とし、初版の必須条件にはしない。

## 挙動の提案（2026-11-27 JST、承認前）

長文ログが後からの履歴閲覧を占有しないよう、状態を発言ごとに決める。最新の発言は今までどおり読めることを優先し、折りたたみで既読の条件や送受信は変えない。以下は確認用の提案で、実装開始・確定仕様ではない。

| 場面 | 提案する挙動 |
| --- | --- |
| 窓を開く／新着が届く | 最新の発言は既定で展開。以前の長文は、手動の指定がなければ3表示行のプレビューにする。「新着」から特定の発言を明示的に開くと、その1件だけ展開。ほかの発言を一斉に開閉したり、現在の表示先を変更する新ルールを加えたりしない。 |
| 対象と判定 | ユーザー発言・返信とも同じ。今の本文幅とフォントで折り返した実表示の冒頭最大3行を使う。改行や空行も行として扱う。全体が3行以内なら省略・開閉操作はなし。作業領域が極端に狭い場合は収まる完全な行だけを表示し、枠外には出さない。幅・表示倍率が変われば再判定する。 |
| 開閉操作 | カード見出しに「全文を表示／折りたたむ」（狭ければアイコン＋アクセシブルな名前）。本文クリックやドラッグは現行の選択・コピーのまま。切り替えても同じ発言を表示位置の基準にし、送信・入力フォーカスを動かさない。展開時は文頭から、折りたたみ時はプレビューの冒頭に戻す。 |
| 矢印・ホイール | 折りたたみ中は隠れた本文をスクロールせず前後の発言へ移る。展開中は既存の長文表示と同じく、本文内を動かせる間は本文をスクロールし、端で前後の発言へ移る。 |
| 保持 | 手動の開閉は同じ起動中、カードの移動・窓の開閉・幅変更をまたいで発言ID単位で保持。別の発言には波及しない。再起動は既定状態に戻し、DBや設定には書かない。 |
| 原文・既読 | 見えているプレビューは表示専用。「全文コピー」はどちらの状態でも完全な原文。折りたたんだことやレイアウト更新だけで既読にしない。既存の閲覧操作と明示的既読を維持し、まだ配置されていないカードを既読にしない。 |

構造案: 履歴表示に、発言IDごとの表示状態と、実際の表示行から作るプレビューを加える。既存の履歴・下書きの共通ネイティブ描画とスクロールのうち、展開時の履歴経路を維持する。原文の部分保存、固定文字数、作業番号を含む識別子や診断、専用のテスト起動手順は加えない。本文のMarkdown化、画像、時間経過の非表示、ブックマークは別範囲。

検証案: 既存の共通テストで、短文・改行・長い日本語ログ・絵文字、狭い枠と幅変更、最新と指定新着の初期表示、発言ごとの独立・起動中保持、展開中の末尾と再折りたたみ、全文コピー・既読・入力欄の非回帰を確認する。描画実測はWindowsで、試験データに実会話を使わない。

状態: 設計提案を提示し、ユーザーの確認待ち。アプリ、テスト、DBは未変更。次: 初期状態・保持・開閉位置と操作の承認または修正点を反映してから実装する。mainは更新しない。
