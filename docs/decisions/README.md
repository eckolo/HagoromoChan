# 設計・運用上の決定記録

重要な選択・不採用理由・制約・変更時の影響を残す。決定は `ADR-<連番>-<slug>.md` に記録し、採用日・状態（提案／採用／廃止／置換）・対象 ID・背景・選択肢・決定・理由・影響・検証を記載する。

後から変更する際は既存記録を黙って上書きせず、置換先や変更理由を追跡可能にする。決定記録はユーザーの指示や確定仕様を変更する権限ではない。
