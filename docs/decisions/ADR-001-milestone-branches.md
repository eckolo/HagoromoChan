# ADR-001 マイルストーン別ブランチと進捗公開

- 日付: 2026-11-25
- 状態: 置換（[ADR-002](ADR-002-merge-only-main.md) により進捗公開・統合方法を改定。以下は当時の決定記録）
- 対象: MGMT-01

## 背景

マイルストーンごとに独立して作業し、必要な他枝の成果を取り込み、完了時に main に戻す運用をユーザーが指定した。並行作業や会話の切り替えでも全体状況を追跡する必要がある。

## 選択肢と決定

- main にすべて直接コミットする方式は、未完了の実装を混入させやすいため採用しない。
- 進捗を作業ブランチだけに持つ方式は、全体進捗を単一の場所で確認できないため採用しない。
- 各 ID の専用作業ブランチと main の管理文書を組み合わせる。必要時に管理記録のみの変更を別の記録更新ブランチから main に公開する。実装の統合は完了条件を満たすまで待つ。

## 影響と対策

管理文書の並行更新では競合が発生し得る。全体一覧は管理窓口で直列化し、最新 main から記録更新を行い、対象外の変更を持ち込まない。個別記録は ID ごとに分離する。依存枝の取り込みは固定 SHA と理由を記録し、未完了の成果を間接的に main へ入れない。完了時は履歴を保つマージコミットを原則とし、統合後に読み戻す。

詳細は [開発運用手順](../operations/development-workflow.md)。
