# ADR-002 main のマージ専用運用

- 日付: 2026-11-25
- 状態: 採用
- 対象: MGMT-02
- 置換元: [ADR-001](ADR-001-milestone-branches.md)

## 背景・決定

ユーザーは main のブランチツリーからマイルストーンの完了時点を一目で識別できる運用を希望した。従来の途中進捗公開と fast-forward による記録更新を廃止する。

- main の更新は完了条件を満たした `milestone/<ID>-<slug>` からの2親マージ（`--no-ff` 相当）に限る。第1親は直前の main、第2親は検証済み作業枝の HEAD。メッセージに ID と名称を含める。
- 管理文書だけの変更も同じ。直接コミット、fast-forward、squash、rebase 統合を禁止する。例外はユーザーの事前明示承認が必要。
- 完了予定記録をマージ前に作業枝で整える。main へマージされ読戻しを確認した場合のみ完了として報告する。完了報告を理由とする後続コミットは作らない。
- 完了枝を第2親の位置に保持し、main へ移動しない。過去の main 履歴および MGMT-01 の当時の記録は書き換えない。
- 途中進捗は各作業枝に保存。main の一覧は登録・統合時の確定記録であり、最新一覧は各枝の個別記録を照合して集約する。単独の登録・運用改定・訂正は管理系マイルストーンのマージで反映する。

## 理由と影響

main の first-parent 履歴を完了マージの単位で把握しやすくする。途中状態の確認は main だけでは完結しないため、ROADMAP に作業枝を記載し、全体報告時に枝の最新記録も参照する。GitHub の強制ブランチ保護設定はこの決定だけでは変更しない。現行の詳細手順は [開発運用手順](../operations/development-workflow.md) を参照。
