# ロードマップ

ここは承認済みマイルストーンの ID・目的・優先順位・依存関係の正本（main 掲載版）である。進捗状態は [PROGRESS](PROGRESS.md)、詳細は [milestones](milestones/README.md) を参照する。

## 現在の定義

| ID | 名称 | 優先順位・着手条件 | 依存 ID | 作業ブランチ | 詳細 |
| --- | --- | --- | --- | --- | --- |
| MGMT-01 | 進捗管理手法の策定 | 最初に実施 | なし | `milestone/MGMT-01-progress-management` | [MGMT-01](milestones/MGMT-01.md) |

アプリ本体のマイルストーンはユーザーが別途定義する。現段階では登録・採番・優先順位付けをしない。既存の通信実証は要求仕様・構成の現状として記録し、未承認のアプリマイルストーンにはしない。

## 更新方針

- 管理系 ID は `MGMT-01` 形式とする。アプリ本体の採番形式はユーザーの提示に従い、重複しない ID を登録する。
- ID は登録後に原則変更・再利用しない。名称変更や範囲変更は個別記録に履歴を残す。
- 優先順位は着手順の目安、依存関係は着手・統合の条件として別々に扱う。依存グラフに循環を作らない。
- 新規登録時はユーザーと合意した目的、範囲、完了条件、依存関係を個別文書に定義する。未確定事項は明記する。
- 完了済みの行も履歴として残す。再対応・追加対応は原則新 ID とし、既存 ID の再開が必要な場合は理由を明示する。
