## 更新ルール

- 状態定義と運用は [開発運用手順](operations/development-workflow.md) に従う。
- 途中進捗は各作業枝の個別記録を更新する。全体報告時は main の一覧と各枝の最新記録を突き合わせて集約する。
- main の一覧は完了マージ等の確定点で更新する。直接コミット、途中公開用の fast-forward 統合を行わない。
- ユーザー側の対応が必要なら具体的な依頼、担当、再開条件を記載する。
- 完了マージの存在・親関係・読戻し結果を確認する。候補上の完了表示はマージ成立前には効力を持たない。
