### ユーザーの実機確認

1. M09ブランチの最新コミットを取得・切替後、`scripts/Update.ps1` で通常の起動先を更新する。Windowsのアニメーションがオフの場合は、本体を右クリックして **キャラクターの動き → 常に動かす** を選ぶ。この枝からの全体ビルドはM09単体で、前版の一時的なM04結合ビルドとは構成が異なる。
2. メッセージを送ったらカーソルを本体から離す。受付時に手元へ目を落としたあと、顎に指を添え、肩を据えて指の側へ首をかしげ、少し間を置いて正面へ戻る様子を数秒見る。切り替わった瞬間と揺れている間の両方で、頭や目の大きさが揃っていることを確かめる。返信待ちに履歴をスクロールする、またはメモ帳などの窓を動かすと、そちらを向く。操作をやめると考える姿勢に戻る。
3. 返信が来たら小さく跳ねる。同じ履歴を開き直しても再び跳ねないこと、入力やドラッグが動作中もできることを確認する。「動かさない」を選ぶと静止する。OSに追従する設定へ戻すには「Windowsに合わせる」を選ぶ。
4. 目が自然に開いて見えるか、顔の向きと足元が安定するかを標準・中・小で見る。独自の `mascot.png` を使う場合は対応するアクションパックを用意する。
5. 表示倍率100%の画面で、本体の端から約80ピクセルの所にカーソルを約0.3秒置き、顔が向いたら約110ピクセルまで離す。そこでも追い続け、120ピクセルを超えると通常の待機に戻ることを確認する。返信待ちでも同様に試せる。
6. 本体から離れた位置で会話履歴を上下にスクロールする。履歴が進む・戻るどちらでも顔はカーソルの側を向き、操作を止めると約1秒後に従来の待機へ戻る。入力欄で文字を打つ、状態表示をクリックする場合も試す。
7. 未読が残ったまま、カーソルを本体と操作中のパネルから離す。羽衣ちゃんが胸に片手を添え、約7秒に一度、見えている新着の吹き出しへ目を向けることを確認する。吹き出しを閉じて「新着」ボタンだけを見せた場合も試す。最後の未読を✓で既読にすると通常待機に戻る。
8. 本体をクリックして開くと、手を高めに上げて挨拶する。もう一度クリックして閉じると、手を胸の脇に上げて静かに一度振る。履歴と入力が両方開いている状態で片方だけを閉じた場合と、最後の面を×で閉じた場合も比べる。

2. リポジトリのルートで次を行い、M09の確認対象SHAを記録する。進行中の別担当のブランチは切り替えて編集しない。

3. Windows 11、.NET 10 SDK、DPI・画面作業領域・モニター構成を記録する。
4. 認証情報・実会話・個人設定をGitに保存しない。素材・制御の検査は合成メッセージと検証用データで行い、実運用のDB・購読を変更しない。
5. 稼働中の配置へ直接上書きせず、M08の既存Build.ps1で新しい候補を作る。実運用への配置・再起動は別段階で扱う。
