# M03 v2.0 実装候補の Windows 確認手順

対象: [M03](../milestones/M03.md) / [画面設計 v2.0](../design/M03-screen-design.md)

## 1. 更新と起動

以前のM03候補では、ユーザーによるDesktopのビルド成功、実機起動、会話表示のスクリーンショットを確認した。今回の改訂版はそれとは別の版であり、ビルド・実機検証が必要。

既存Desktopを右クリックの「終了」で終了し、PowerShellでリポジトリルートから実行する。未コミットの作業がある場合は保護する。Relayとtunnel-clientは稼働したままでよい。

```powershell
git status --short
git fetch origin
git switch milestone/M03-character-and-window-ui
git pull --ff-only
dotnet build .\src\HagoromoChan.Desktop --configuration Release
Start-Process .\src\HagoromoChan.Desktop\bin\Release\net10.0-windows\HagoromoChan.Desktop.exe
```

ローカル枝がまだなければ `git switch --track origin/milestone/M03-character-and-window-ui` を使用する。上記はDesktopだけをビルドする。通常の再起動ではビルドせずDesktop.exeを起動するか、ビルド済みなら `Start.ps1 -SkipBuild` を使う。全体ビルド時のファイルロックとトンネル子プロセスの再生成に関する恒久対策は[M08](../milestones/M08.md)の対象である。

新しい画像は同梱済み。以前の独自 `mascot.png` を配置している場合は、その画像が引き続き優先される。低解像度の差替え素材で同梱画像の品質を評価しないよう注意する。

## 2. 確認項目

| ID | 確認 | 期待 |
| --- | --- | --- |
| W01 | 初期起動・通常表示 | 透過背景・羽衣ちゃん単独。過去履歴の無条件新着表示なし。 |
| W02 | 本体クリック→再クリック | 入力・回答が開き、再クリックで全周辺面が閉じる。カーソルを残してもホバーが直ちに出ない。再クリックで開く。 |
| W03 | 一括閉じと通信 | 下書き、未読、送信・返信待ちを失わない。定期ポーリングで同じ状態パネルが再出現しない。新着返信は再表示可。 |
| W04 | ホバー・右クリック・ドラッグ・透過部分 | メニューへ移動可能、他アプリのフォーカスをホバーで奪わない。ドラッグは会話を開かず位置移動。透明領域で背後を操作可能。 |
| W05 | UI統一 | 回答、過去のユーザー発言、入力が同系統の吹き出し。入力見出しなし、尾が反対方向。画面左右の配置変更で尾が反転。 |
| W06 | 固定操作部 | 短い発言、長い発言、複数カード、入力行数の変化を通じ↑↓等のボタン位置が画面上で動かない。 |
| W07 | 履歴の積み上げとホイール | 上で前の発言／ページが上に追加、下で最古側が消える。連打・押し続け・ホイールを確認。古い履歴データは失われない。 |
| W08 | 履歴表示の統一 | 右クリック・ホバーの会話履歴が同じ会話面を開く。別の履歴窓が出ない。ユーザー発言と回答の双方を閲覧できる。 |
| W09 | 通常長文 | 日本語、改行、長いURL、句読点・絵文字・連続文字を含む回答で、吹き出しの本文が全文表示されスクロールバーが出ない。 |
| W10 | 画面を超える長文・複数履歴 | ページ番号と上下操作で全ページに到達できる。内部スクロールなし、末尾や改行を欠落させない。コピーは元の発言全文。 |
| W11 | 長い入力・IME | 複数ページの下書きを入力頁↑↓で移動・編集。全文が保持され送信される。Enter改行、Ctrl+Enter送信、IME変換確定・Escで誤送信しない。 |
| W12 | 新着・既読・保存 | 既読は明示操作のみ。古いページ閲覧中の新着は勝手に閲覧起点を移動しない。閉じて再起動しても未読管理が破損しない。 |
| W13 | サイズ・複数モニター・DPI | 旧大260 DIPが標準。小・中・大で元画像を超えて拡大しない。負座標・左右上下・DPI差・画面端でも操作部を失わない。 |
| W14 | 実際の会話と再試行 | 既存Dot経路の二往復（候補2件→2つ目を詳しく）、送信受付確認・ID再試行・障害時の下書き保持、返信の対応付け。 |
| W15 | 終了・再起動 | Desktopのみ終了し、Relay／トンネルを停止しない。位置、サイズ、最前面を復元する。 |

初回はW01～W10、W13を優先し、続いてW11/W12/W14/W15を確認する。通常サイズとDPI差、既存差替画像の有無も記録する。現在の会話DB・購読・APIキーは変更しない。

## 3. 回帰検証

関連プロセスを使用中のDLLに対して全体ビルドしない。必要に応じ安全に停止した検証環境で以下を行う。

```powershell
dotnet build .\HagoromoChan.sln --configuration Release
dotnet run --project .\tests\HagoromoChan.Tests --configuration Release
```

追加した4項目は文字要素境界の原文保持、履歴積み上げ／範囲、固定領域／原寸以下、旧標準サイズの移行である。これらのC#回帰テストは今回まだ実行していない。WPFの実測テキスト高さやフォーカスを純粋ロジックテストだけで確認済みとはしない。

## 4. 返却

`git rev-parse HEAD`、ビルド結果、回帰結果、実機確認項目の合否・未実施、必要なスクリーンショットを返す。APIキーや実会話の機密情報は共有しない。新しい実装候補の実機確認が成立するまでM03はmainへマージしない。
