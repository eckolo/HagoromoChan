# 要求仕様

この文書は全体に適用する確定済みの要求と制約を記録する。個別の実装範囲・完了条件は各マイルストーンで定義する。本書はアプリ本体のマイルストーン一覧ではない。

## 目的・確定している方向性

- Windows で動作する、窺かのようなデスクトップ常駐アプリを目指す。
- 最初の対象は既存の ChatGPT Dot「羽衣ちゃん」との会話。自作 UI に入力し、同じ UI で返信を受ける。公式ブラウザ画面をそのまま小窓表示する方式は採用しない。
- OpenAI の仕様変更への耐性を重視し、公開された連携仕様を優先する。他のサードパーティ製ブリッジ実装には依存しない方針とする。
- 将来的な対象としてローカル／クラウドの Chat／Work を想定する。新規会話開始、プロジェクト選択、回答発生時の表示、既存会話の継続は長期的な構想であり、現時点の実装・実現可能性を保証しない。
- トンネルはアプリ本体とは別プロセスで起動・管理できるようにする。

## 現行実装で確認済みの範囲

2026-11-25、ユーザーから Windows の自作会話画面で羽衣ちゃんへのテスト発言と返信受信が成功した旨の報告と画面提示があった。基本往復の実証として扱う。複数発言の表示と改行を含む応答は確認できるが、詳細な遅延の内訳、文脈依存の追質問、長期購読維持、全種類の通知などをこの報告だけで検証済みとはしない。

## 今後の仕様確定

2026-11-25 にユーザーが提示した4件のマイルストーンは [ROADMAP](ROADMAP.md) に登録する。羽衣ちゃんのキャラクター表示・吹き出しによる会話 UI を絶対必要機能として最優先にし、基本 UI を実用段階に進めてから他の課題を検討する。Dot の自発発言、Mini からアクセス可能な Chat や別 Work との送受信、通信状態の可視化は個別記録で扱う。詳細仕様と完了条件は着手時に確定する。変更時は本書または個別記録を更新し、重要な選択理由は [decisions](decisions/README.md) に残す。

2026-11-25 の追加指示により、Windows ログオン時の自動起動、メッセージ・マウスイベントに応じた羽衣ちゃんのアクション、時間経過に応じたランダム移動を将来要求に追加する。詳細は M08～M10 の個別記録で扱い、M03 の画面設計・実装とは分離する。

2026-11-25 のユーザー指示により、M08 を自動起動に加え、ビルド・起動・停止・再起動・関連プロセス管理を整理するマイルストーンに拡張し、優先度を高とする。通常の起動・再起動でビルドを必須としない。Desktop、Relay、トンネルの個別運用を維持し、稼働中のファイルロックや監視される子プロセスの再生成を考慮する。起動方式・認証情報管理等の詳細は M08 の着手時に設計する。M03 の範囲から分離する。

2026-11-25 のユーザー指示により M06 を通信状態の管理・障害復旧まで拡張し、優先度を高へ変更する。ローカル購読の保存状態とクラウド側の成立状態、HTTP 配信受理と実際の回答到着、返信待ちと未読回答を区別する。未回答要求と購読情報を保護しつつ、診断・キャンセル・安全な再登録／復旧の方式を設計する。単なる異常状態で購読や DB を自動削除したり、既存要求を別の購読先へ無断転送したりしない。詳細は M06 の個別記録で扱う。M03 はユーザー受入と最終調整により完了したが、最終版のビルド・回帰・実機残検査を合格扱いにはしない。

2026-11-25 の追加指示により、状態枠の「新着」表記を維持し、履歴窓が一度でもアクティブになること、または履歴表示後の履歴スクロール操作を契機に、該当する新着回答を非新着扱いにする方向で改善する。個別の✓押下を必須にしない。この閲覧操作・新着解除規則の変更は低優先度の [M14](milestones/M14.md) に分離する。M06 は未回答要求と新着回答の状態区別・通信管理・障害復旧を扱う。

2026-11-25 の追加指示（[MGMT-15](milestones/MGMT-15.md)）により、M08完了と通常会話復旧を踏まえM06を中、M04を高に変更する。M09は中のまま早期並行着手候補とし、通信・保存と演出の責務を分離して設計する。M06の障害復旧要件、M14の新着解除要件、完了済みM03/M08の成果は維持する。具体的な並行実装・イベント仕様は着手時に確定する。

2026-11-26 のユーザー承認（[MGMT-17](milestones/MGMT-17.md)）により、当面の他会話アクセスはクラウドChat／クラウドWorkに限定する。ローカルWork対応は今回の開発範囲から外す（長期構想の可否は未確定）。[M05](milestones/M05.md)で回答の受信・受信元の識別・スレッド単位の履歴を管理し、既存Dot会話の送受信・保存を保護する。[M18](milestones/M18.md)で既存の縦方向履歴閲覧に加えて横方向の会話切替を実装し、[M19](milestones/M19.md)で受信済み会話への発言送信・返信の相関管理を扱う。未受信会話の検索、新規会話作成、過去全履歴の同期、リッチコンテンツの専用表示、Work実行管理は別途検討とし、新規マイルストーンには登録しない。公開された接続手段と権限をM05初期工程で種別別に調査し、自動取得／明示転送、受信可否／送信可否を区別する。未確認の機能を保証せず、対応範囲を縮小する場合はユーザーと合意する。
