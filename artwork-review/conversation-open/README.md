# 会話窓を開く首かしげ

通常立ち絵の首の支点 `(145,188)` を使い、画面左へ首をかしげる3コマ。入りで片眉と視線が動き、頂点で口を小さく開き、戻りで笑みが戻る。肩に掛かった毛先は襟と羽衣の位置に沿って残した。髪飾りは画面左、帯の飾りは画面右にある。

[明暗背景の等倍比較](compare-260.png) · [再生見本（APNG）](playback-260.png) · [画素差](body-difference.png) · [透過スプライト](sprite.png) · [比較基準](reference-neutral.png)

## 切り出しと再生

各セルは288×368 px、足アンカーはセル内の `(144,360)`。通常立ち絵の座標のまま頭・表情・髪を調整した。頭頂の高さは頭の傾きに合わせて変化する。

| コマ | 切り出し矩形（x, y, 幅, 高さ） | 時間 | 頭頂 y¹ |
| --- | --- | ---: | ---: |
| 通常 | 基準PNG全体 | — | 11 |
| 入り | 0, 0, 288, 368 | 180 ms | 12 |
| 頂点 | 288, 0, 288, 368 | 180 ms | 14 |
| 戻り | 576, 0, 288, 368 | 220 ms | 12 |

¹ 不透明度128/255以上。足裏の最下行は通常も3コマも `y=359`。

等倍比較の左右端は製品の通常立ち絵。間に入り・頂点・戻りを並べた。96 DPIで高さ260 DIP、1枠177×260 px。ウィンドウ幅は約176.67 DIP、下端揃えのセルの表示高は約225.74 DIP。上段は明色、下段は暗色。再生見本は明色背景で通常を1秒表示してから580 msの首かしげを繰り返す。

## 画素の確認

基準は同梱 `MascotReactions.png` の左上 `(0,0,288,368)` を原寸で切り出した `reference-neutral.png`（Git blob `802220f89a40e9ce58d775e6e8281545393de11e`）。参照セルと各コマを同じ座標で重ね、RGBAの4値のいずれかが異なる画素を数えた。矩形は各セルの左上を原点とする。画素差画像は、変化のある可視画素が橙、同一の可視画素が灰。

| 確認範囲 | 比較画素数／コマ | 入り | 頂点 | 戻り |
| --- | ---: | ---: | ---: | ---: |
| 可視の首・衣装・足（注） | 24,920 | 0 | 0 | 0 |
| 左肩 `(110,217)` から11×8 px | 88 | 0 | 0 | 0 |
| 右肩 `(166,217)` から11×8 px | 88 | 0 | 0 | 0 |
| 襟 `(135,201)` から19×19 px | 361 | 0 | 0 | 0 |
| `y=214` から下の全幅（羽衣・袖・腕・裾・足・透明余白を含む） | 44,352 | 0 | 0 | 0 |
| 足元 `y=326…367` の全幅 | 12,096 | 0 | 0 | 0 |

注：基準セルの `y≥179` でアルファが0より大きく、同一座標にある同梱 `MascotThinkingHead.png` の頭マスクが透明な画素。頭マスクは髪と胴体の境界の照合に使用した。髪飾り・目・衣装の白布と鶴・輪郭を明暗背景で目視した。全コマでセル境界上の非透明画素は0、完全透明画素に残る非ゼロRGBも0。
