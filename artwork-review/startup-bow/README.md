# 起動のお辞儀

再試用版 `28335730` の3枚の作画から伏し目、閉じたまぶた、流れる前髪を取り、製品の正面セルに肩の位置と胴の幅を合わせた。首の下の襟だけが前屈についていき、襟合わせの下端・両肩・袖・手・裾・足は元の座標に残る。頂点では顎が襟の上まで沈む。

[明暗の等倍比較](compare-260.png) ・ [再生見本](playback-260.png) ・ [通常立ち絵との画素差](body-difference.png) ・ [基準セル](../conversation-open/reference-neutral.png)

各セルは288×368 px、足アンカーは `(144,360)`。スプライトは864×368 px。通常立ち絵から入り・頂点・戻りを経て通常へ戻る。再生時間は**520＋300＋600＝1,420 ms**。再生見本の最初の静止1秒はこの時間に含まない。
