# 起動のお辞儀 ｜ 素材レビュー

[透過スプライト](sprite.png) ・ [260 DIP相当の比較](compare-260.png)

比較画像は左から **基準立ち絵 → 移行 → 頂点 → 戻り → 基準立ち絵**。上段は明色、下段は暗色の背景。各列は96 DPI想定の176×260 pxのウィンドウ、反応セルの描画域は176×225 px（上から35 px）。両端は指定コミットの `Mascot.png` を静止時の接地・寸法に合わせたもの。

- RGBA PNG、864×368 px。左上を原点に、切り出し矩形 `[x,y,幅,高さ]` は `[0,0,288,368]`、`[288,0,288,368]`、`[576,0,288,368]`。共通足アンカーは各セルの `(144,360)`。
- 再生案は既存の静止 → 左260 ms → 中150 ms → 右300 ms → 既存の静止。全3コマとも足裏の最下行は不透明度50%以上で y=359。頭頂はセル内で y=15 → 47 → 17。頂点で上体・襟・肩が沈み、両袖が寄り、手が揃う。比較画像で顔・鶴・飾りの向きと、明暗の輪郭を目視。
- 三つの別作画を共通の倍率・足基準で配置。参照は `86fceaf8f7742112f7c0457c85ce02b400be06ad` の同梱素材。元の静止から移るところで開いた手が腹前へ寄る間隔は、再生で確認したい箇所。
