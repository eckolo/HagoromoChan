# キャラクター操作の作画候補

起動、メニュー表示、会話窓の開閉に対応する差し替え検討用素材。のぞき込みはメニューが出る側に合わせて左右を別に描いた。4演出、左右差を含めて5本、3コマずつの計15枚。PNGの比較と単体再生まで確認。アプリへの組み込み・採用判断・Windows実機での確認は未実施。

**切り出し。** 各PNGは864×368 px。左上を原点に、`[x,y,幅,高さ]` は左から `[0,0,288,368]`、`[288,0,288,368]`、`[576,0,288,368]`。足アンカーは各セル内の `(144,360)`（両足中央・足裏の直下）。既存の静止 → 左 → 中 → 右 → 既存の静止の順。機械可読の矩形・時間・実測範囲は [frames.json](frames.json) を参照。

**比較の見方。** 等倍比較は左から静止・移行・頂点・戻り・静止。上段は明るい背景、下段は暗い背景。同梱立ち絵 `Mascot.png` を既存の静止セルの表示高・足位置に合わせて両端の比較基準にした。96 DPIで標準260 DIPのウィンドウを想定し、1枠176×260 px、セルは176×225 px、上端は35 px。ブラウザーで原寸表示するとこの寸法で見比べられる。再生見本は同じ寸法のAPNG。繰り返しを見やすくする静止1秒は演出時間に含めない。

**選定メモ。**

- お辞儀は襟と肩が帯へ近づき、手が腿の前に揃う稿を選んだ。移行から頂点までの頭頂の差はセル内で32 px。既存の下向きと見分ける手がかりは、目より肩・襟・袖に出る。静止から両手を腹前に寄せる変化は3コマの中では大きい。
- のぞき込みはどちらも顔と上体がメニュー側へ寄る。金の髪飾りは画面左、帯の結びは画面右。襟合わせと鶴の向きも維持した。静止から移行で髪の横幅が少し細くなるので、アプリ上での切り替わりを見るときはここを確認する。
- 首かしげは肩と裾を保ったまま、入りで首を傾け、頂点で口が開き、笑顔へ戻る稿を選んだ。目のラインから見積もった傾きはおよそ10° → 13° → 7°。表情と髪が動き、足を軸にした全身の回転は使っていない。
- 閉じる会釈は、手を上げず、目を閉じて襟と肩がわずかに沈む。入りから頂点までの頭頂差は6 pxで、起動のお辞儀より浅い。時間案は395 ms、起動は710 ms。

**透明と接地。** 全15コマで不透明度50%以上の最下行は `y=359`。足裏付近（最下行から2 px上）の左右端の中点は `x=144` から最大0.5 px差。セル境界上の非透明画素と、完全透明画素に残った色成分はいずれも0。明暗の両背景でコマ間の位置・顔・線・衣装の白布と輪郭を目視した。比較見本は素材の描画確認用で、Windowsのスクリーンショットではない。
