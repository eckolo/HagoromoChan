# 立ち絵素材

`Mascot.png` は本開発会話で生成した「羽衣ちゃんの可憐な巫女装束姿」の全身イラストを、M03の試作向けに背景分離・縮小・減色した暫定立ち絵（123×180、透過PNG）。第三者のMini素材の抽出ではない。正式なキャラクター素材の確定は実機レビューで行う。

より高解像度の透過PNGを `%LOCALAPPDATA%\HagoromoChan\mascot.png` に配置すると、次回 Desktop 起動時に同梱画像より優先する。HAGOROMO_DATA_DIR を指定した場合はそのディレクトリを使用する。不正な画像は同梱素材へフォールバックし、理由を表示する。
