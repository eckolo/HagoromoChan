# 立ち絵素材

`Mascot.png` は本開発会話で生成した「羽衣ちゃんの可憐な巫女装束姿」の全身原画から背景を分離し直した高解像度版。旧123×180px素材を拡大したものではない。採用版は530×780pxの透過PNG（RGBAフルカラー、582575 bytes、Git blob SHA `5695e81e60304bd722eb632828a7f8a27fe034ca`）。第三者のMini素材の抽出ではない。

表示の標準は旧「大」に相当する高さ260 DIP（中180・小120）。実際の表示寸法はモニターDPIと作業領域、画像の物理ピクセル数のすべてで上限を設ける。画像を原寸以上に拡大しない。高DPIで要求サイズが素材の上限を超える場合は縮小倍率1.0までに制限する。素材は読み込み時に96 DPIへ正規化し、縦横比を維持する。

任意の透過PNGを `%LOCALAPPDATA%\HagoromoChan\mascot.png` に配置すると次回起動時に優先する。HAGOROMO_DATA_DIRを指定する場合はその場所を用いる。小さい差替画像も拡大しない。不正なPNGは同梱素材へフォールバックし、理由を通知する。画像の見た目・実機DPIでの描画確認はM03の実機レビュー対象。

## M09の標準アクション

`MascotReactions.png` は上記の立ち絵を人物参照に画像生成で描き直した全身9姿勢。髪飾り、橙色の髪、緑の丸い瞳、鶴柄の着物を揃えた。透過PNGを864×1104ピクセルに整列し、288×368ピクセルの各セルの足元を共通の基準に合わせた。Git blobは `2ae4cc4601a8d842945ceef4e641aeb8d7217154`。

| 左 | 中央 | 右 |
| --- | --- | --- |
| 正面 | 見上げる | 手元を見下ろす |
| 左の窓を見る | 右の窓を見る | 短いまばたき |
| 手振り | 小さなジャンプ | 困った顔 |

標準立ち絵の視線は顔・髪・肩を含む各姿勢を表示する。待機の閉眼は約4.8秒に一度、150ms。独自の立ち絵とパックの条件は[M09設計](../../../docs/design/M09-character-reactions.md)に従う。

回答待ち用の [`MascotThinking.png`](MascotThinking.png) は正面のセルを人物参照に、顎に人差し指を軽く添えた姿勢を描き下ろしたもの。288×368の透過PNGで、足元の基準は他の姿勢と共通。描画時に約4.6秒かけて呼吸と小さな体の揺れを加える。素材のSHA-256は `80A5417BD64BCF7A8106539879720C425FB636F31B37CBB4B1FD763A0F17119C`。
