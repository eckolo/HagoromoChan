# 立ち絵素材

`Mascot.png` は本開発会話で生成した「羽衣ちゃんの可憐な巫女装束姿」の全身原画から背景を分離し直した高解像度版。旧123×180px素材を拡大したものではない。採用版は530×780pxの透過PNG（RGBAフルカラー、582575 bytes、Git blob SHA `5695e81e60304bd722eb632828a7f8a27fe034ca`）。第三者のMini素材の抽出ではない。

表示の標準は旧「大」に相当する高さ260 DIP（中180・小120）。実際の表示寸法はモニターDPIと作業領域、画像の物理ピクセル数のすべてで上限を設ける。画像を原寸以上に拡大しない。高DPIで要求サイズが素材の上限を超える場合は縮小倍率1.0までに制限する。素材は読み込み時に96 DPIへ正規化し、縦横比を維持する。

任意の透過PNGを `%LOCALAPPDATA%\HagoromoChan\mascot.png` に配置すると次回起動時に優先する。HAGOROMO_DATA_DIRを指定する場合はその場所を用いる。小さい差替画像も拡大しない。不正なPNGは同梱素材へフォールバックし、理由を通知する。画像の見た目・実機DPIでの描画確認はM03の実機レビュー対象。

## M09の標準アクション

`MascotReactions.png` は上記の立ち絵を人物参照に画像生成で描き直した全身9姿勢。髪飾り、橙色の髪、緑の丸い瞳、鶴柄の着物を揃えた。透過PNGを864×1104ピクセルに整列し、288×368ピクセルの各セルの足元を共通の基準に合わせた。Git blobは `2ae4cc4601a8d842945ceef4e641aeb8d7217154`。

| 左 | 中央 | 右 |
| --- | --- | --- |
| 正面 | 見上げる | 手元を見下ろす |
| 左の窓を見る | 右の窓を見る | 短いまばたき |
| 手振り | 小さなジャンプ | 困った顔 |

標準立ち絵の視線は顔・髪・肩を含む各姿勢を表示する。待機の閉眼は約4.8秒に一度、150ms。独自の立ち絵とパックの条件は[M09設計](../../../docs/design/M09-character-reactions.md)に従う。

思案用の[編集元絵](MascotThinking.png)は288×368の透過PNG。通常待機の頭身・髪・目の輪郭を保ち、片眉を少し上げ、口を小さく結び、指を顎に添えている。アプリは同じキャンバスの[胴](MascotThinkingBody.png)、[頭](MascotThinkingHead.png)、[右上を見る目の差分](MascotThinkingEyes.png)、[手と袖](MascotThinkingHand.png)をこの順に重ねる。目の差分は全48位相のうち10〜38（0始まり）でだけ表示し、頭と同じ支点・角度で描く。胴の襟元は首を傾けたときに見える範囲まで補っている。これは同梱素材の表示方法で、独自パックの `thinking` には従来のコマをそのまま使える。

元絵の左上から測って、首の支点は (145,188)、顎と指の接点は (138,181)。頭は首を支点に画面左へ最大5.5度傾け、手は顎の接点の移動分だけ平行移動する。肩と足は一周4.6秒を通して固定する。

## 未読がある時の立ち絵

[胸元に手を添えた元絵](MascotUnread.png)は288×368の透過PNG。通常待機の正面セルに、胸元の片手と曲げた袖を描き足して、髪・顔・目・足元の大きさと位置を揃えた。[視線用の透過PNG](MascotUnreadEyes.png)は同じ大きさの4セルを2×2に配し、左上に左、右上に右、左下に上、右下に下を収録する。新着を一瞥する時は目の部分だけを元絵に重ねる。

## 吹き出しを閉じるときの手振り

[袖を曲げた姿勢](MascotFarewellBody.png)に、[閉じるときの手](MascotFarewellHand.png)を重ねる。どちらも正面の立ち絵と同じ288×368のキャンバスを使う。手のひらを胸の脇に軽く上げ、袖口 (90.8, 231) を支点に画面左へ最大9度振って戻す。頭・胴・足の位置は固定。開くときの手振りには従来の9姿勢シートを使う。
